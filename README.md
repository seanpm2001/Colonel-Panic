# Colonel Panic

`🪖️🐧️💾️ The official source repository for the Colonel Panic project, a mascot for Kernel Panics. Pronounced Kernel Panic.`

## Name

The name is a pun based off of the rank of Colonel (which is pronounced kernel) and kernel panics on UNIX-like systems.

## Mascot

The current logo is a Tux penguin with a hat. I tried a few methods, such as adding a uniform (it didn't turn out right, so I removed it) I tried to add Finnish insignia, but that didn't turn out right either. For now, I am just keeping the hat.

The logo is just a prototype. The one flaw I got from feedback was that the eyes aren't surprised enough, and should look panicked. I also want the logo to represent more UNIX-like systems, rather than just Linux, but I don't know how to represent this and the Colonel rank at the same time.
